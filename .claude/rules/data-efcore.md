# EF Core

- **`AsNoTracking()` on every read-only query.** The change tracker costs memory and time for data
  nobody will modify. This is the most common EF Core performance mistake and an interviewer may
  look for it.
- **No lazy loading.** Use explicit `Include` for what you need. Lazy loading turns one query into N
  silently, and you will not notice until the trace shows it.
- **Project to a record, do not return entities.** No EF entity type appears in a signature outside
  this project. The agent layer and the API see plain records only.
- **Configure with `IEntityTypeConfiguration<T>` classes**, one per entity, not a growing
  `OnModelCreating`.
- **Money columns are configured `decimal(18,2)` explicitly.** EF Core warns otherwise, and warnings
  are errors here.
- **Migrations are generated by the CLI**, never hand-written, and committed. A schema change without
  a migration is not a schema change.
- **The seed is deterministic** — a fixed random seed, idempotent, byte-identical on a re-run.
  The eval suite depends on this.
- The model never sees SQL and never composes a query. It calls tools; tools call repositories.
